# Portfolio

A minimal, personal portfolio built with Node.js, Express, and EJS. Features a home page with an about section and skills breakdown, and a works page with a project grid and image carousel modal.

## Stack

- **Backend** — Node.js, Express
- **Templating** — EJS with shared partials (head, nav, footer)
- **Styling** — Vanilla CSS with CSS custom properties
- **Fonts** — Josefin Sans, Jost (Google Fonts)

## Features

- Fixed sidebar navigation with social links
- Project grid with hover effects
- Click-to-open modal with an image carousel (prev/next buttons, dot indicators, scroll-wheel navigation, Escape key to close)
- Tech stack pills per project
- Dynamic copyright year in footer via EJS
